# amazon-jobs

Interactive page of Mai Vo's Amazon Summer 2027 internship applications, made for referrer review.

- `index.html` is a single self-contained file (all CSS/JS inline, cover image embedded). Open it in a browser to use the search, filters, Mark reviewed buttons, and the Freight / Duties / Insurance / Handling explainer.
- Each job card links to the Amazon posting and to the tailored resume (Google Drive). The resume links work once the Drive folder is shared.
- Live site (GitHub Pages): https://ellymaivo-rgb.github.io/amazon-jobs/
